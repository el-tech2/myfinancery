MYFINANCE - STRUKTUR SATU FOLDER UNTUK GITHUB

Letakkan semua file berikut pada level/root folder yang sama:
- index.html
- style.css
- app.js
- bri.png
- seabank.png
- gopay.webp
- dana.jpg
- cash.png

Path gambar di app.js sudah menggunakan ./nama-file.
Path CSS dan JavaScript di index.html juga menggunakan ./style.css dan ./app.js.

PENTING:
Nama file harus sama persis, termasuk huruf besar/kecil dan ekstensi.
Jika gambar tidak tampil di GitHub Pages, cek kembali nama file gambar di repository.
